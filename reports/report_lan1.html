1. Firmware & Phần Cứng (Trạm Quan Trắc)

Cải Tiến & Tối Ưu Code

Hoàn thành
  • Tái cấu trúc (Refactoring): Chuyển đổi từ code nguyên khối sang cấu trúc module hóa (tách biệt Aws_glitch.ino và config_globals.h), giúp dễ dàng bảo trì và mở rộng.
  • Đa nhiệm cảm biến: Đọc đồng thời dữ liệu từ cảm biến DHT11 (Nhiệt độ/Độ ẩm) và Geiger-Müller J305βγ (Phóng xạ) mà không gây chặn (blocking) luồng xử lý chính.
  • Xử lý tại biên (Edge Computing): Tính toán trực tiếp các chỉ số uSv/h và CPM (Counts Per Minute) ngay trên vi điều khiển trước khi gửi đi.
  • Kết nối bảo mật: Sử dụng chứng chỉ AWS IoT (Certificates) để thiết lập kết nối MQTT an toàn, tích hợp cơ chế tự động kết nối lại (Auto-reconnect).

2. Backend Serverless (AWS)

Hạ Tầng & Xử Lý Dữ Liệu

Hoàn thành
  • Kiến trúc Event-driven: Sử dụng AWS Lambda để xử lý sự kiện từ IoT Core, đảm bảo khả năng mở rộng và tối ưu chi phí.
  • Luồng dữ liệu chuẩn hóa:
    • Data Ingestion: Thu thập dữ liệu thô từ thiết bị.
    • Internal Processing: Xử lý, làm sạch và lưu trữ vào DynamoDB (Sensor Data, Device Status, System Logs).
  • Tích hợp AI: Triển khai lambda_chat_ai.py kết nối với Google Gemini AI để phân tích dữ liệu và trả lời câu hỏi người dùng.
  • API Gateway: Xây dựng hệ thống RESTful API bảo mật để cung cấp dữ liệu cho Frontend.
  • Tự động hóa: Sử dụng EventBridge để kích hoạt các tác vụ định kỳ (ví dụ: tổng hợp dữ liệu hàng ngày vào 01:00).

3. Frontend & Giao Diện Người Dùng

Trải Nghiệm & Trực Quan Hóa

Hoàn thành
  • Thiết kế hiện đại: Giao diện Glassmorphism (Kính mờ), hiệu ứng 3D và Aurora Background tạo cảm giác công nghệ cao.
  • Biểu đồ tương tác: Tích hợp Chart.js với plugin Zoom/Pan, cho phép người dùng xem chi tiết lịch sử dữ liệu theo nhiều khung thời gian.
  • Trợ lý ảo AI: Widget Chatbot thông minh, hỗ trợ người dùng tra cứu thông tin và phân tích dữ liệu hệ thống bằng ngôn ngữ tự nhiên.
  • Đa ngôn ngữ: Hệ thống hỗ trợ chuyển đổi ngôn ngữ linh hoạt (i18n).

4. Mở Rộng & Bảo Mật

Mở Rộng Hệ Thống

Hoàn thành
  • Tích hợp thành công Trạm 02 vào hệ thống.
  • Cập nhật cấu hình Firmware để hoạt động độc lập.
  • Hiển thị dữ liệu đa trạm trên Dashboard.

Bảo Mật & User

Hoàn thành

  • Hoàn thiện quy trình Đăng ký/Đăng nhập.
  • Phân quyền truy cập dữ liệu (Admin/User).

5. Kế Hoạch & Hướng Phát Triển

Điều Khiển Hai Chiều (Device Control)

Đang phát triển

Cho phép người dùng gửi lệnh từ Web xuống thiết bị thông qua API và MQTT.

  • Backend: Đã có API /device-control.
  • Firmware: Đang hoàn thiện logic xử lý lệnh (Reset, Bật/Tắt còi).
  • Frontend: Đang xây dựng Control Panel.

Hệ Thống Cảnh Báo Chủ Động (SNS)

Kế hoạch

Tích hợp Amazon SNS để gửi cảnh báo tức thì khi chỉ số vượt ngưỡng.

  • Gửi Email cảnh báo.
  • Gửi SMS cảnh báo (tùy chọn).
