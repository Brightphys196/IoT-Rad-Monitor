    Triển khai 20 Lambda Functions, API Gateway, DynamoDB, Cognito.

  • Tính Năng Nâng Cao

    Rà soát lỗ hổng bảo mật, tối ưu chi phí AWS và hiệu năng hệ thống.

  • Viết Báo Cáo Luận Văn
